Private discovery review

Owner sign-in required. Edits and imported proposals are stored privately for review, not automatically published. No remote dataset is fetched from a supplied URL. Verify licences and identity before approval. Audio is reviewed as a permitted recording, not automatically generated. Local batches can save up to 100 new pending proposals. Public dataset import and merge execution are not enabled.

Reviewer sign-in · Public data coverage · Private photo/video upload library is not available in this build

JSON fields are validated. Include title,source_url,licence,attribution; translations need place_id,language,text; coordinates need coordinate_source.

Dataset preflight

Inspect a local JSON file before importing. Nothing is sent or saved by the preflight check. Use an array of up to 100 proposals: {id,kind,payload}. Source URL, licence and attribution are required for every proposal. Imported status is always pending. Correct every rejected row before a batch can be saved. Imports create new UUIDs only and never overwrite existing proposals. Explicit confirmation sends the batch to this site's private owner workspace.

Duplicate comparison

Compare two source IDs from the current public dataset. Matching names and nearby coordinates are only clues, not proof. A merge proposal never deletes or changes a public record.
