Submissions are currently paused. You can review the fields and privacy notice, but sending is disabled and nothing entered here is saved. When submissions reopen, an entry is saved in a private database that only the SRCHN owner can read, and is reviewed by hand. Nothing is published automatically, submitting does not create a listing, and no reply is sent because we collect no contact details.

Please do not enter email addresses, phone numbers, ID numbers or any personal details. Entries that look like they contain them are rejected.

Privacy and retention

  • While submissions are paused, nothing entered on this page is saved. When submissions reopen, we store only the fields above, the time, and a review status. This form does not ask for or save a name, email, phone, ID document or file upload, and it does not store IP addresses. Our hosting provider, Cloudflare, handles the network request itself under its own policies.
  • Entries older than 30 days are deleted by a daily scheduled job, so removal normally happens within about 31 days. If that job fails, entries can stay until it next runs successfully. Database restore points can keep deleted rows for up to 7 more days.
  • The form can be switched off at any time, and it is limited to a small number of entries per day.
  • To delete an entry earlier, use the reference shown after you submit it (form below). We cannot look up entries without it. You can also email hi@srchn.in with the place name and the time you sent it.
  • This notice covers this form only. It is a preview test and does not change the terms on other SRCHN pages.
